# Painel de Qualidade

Aplicação desenvolvida em **Python + Streamlit** para centralizar indicadores e informações de qualidade em uma interface web interativa.

## Sobre o projeto

O projeto explora a criação de dashboards operacionais com foco em qualidade, visualização de dados e apoio à análise de informações. A aplicação reúne recursos de tratamento de dados, gráficos interativos, leitura de arquivos e integração opcional com IA.

## Tecnologias

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL
- PDFPlumber
- Azure OpenAI (integração opcional via variáveis de ambiente)

## Funcionalidades

- Dashboard web interativo
- Visualização de indicadores e métricas
- Tratamento e análise de dados com Pandas
- Gráficos interativos com Plotly
- Leitura de planilhas e documentos
- Estrutura preparada para recursos de IA via Azure OpenAI

## Como executar

```bash
pip install -r requirements.txt
streamlit run app.py
```

Para integrações externas, configure as credenciais somente por variáveis de ambiente. Arquivos `.env` e segredos não devem ser versionados no Git.
